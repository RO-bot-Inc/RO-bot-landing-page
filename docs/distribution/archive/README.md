# Archived distribution drafts

Drafts for posts that were promoted before the subscriber list existed (moved here 2026-09-10, Dave: "I don't want to accidentally send them"). The newsletter script only reads `docs/distribution/{slug}.md`, so nothing in this folder can be sent by `npm run newsletter:announce`.

To email one of these posts anyway, copy the file back up one level, bring its email section to the current template (fenced body, `Unsubscribe: [unsubscribe-link]` footer, no `{{first_name}}`, no em dashes), and run the dry run first.

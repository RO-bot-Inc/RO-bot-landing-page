# RO.bot Website — Visual Assets Priority

Reference list of website visual assets in priority order. Use this when planning new pages, refreshing existing ones, or sourcing screenshots.

## Priority Order

1. **Hero image** — phone mockup in shop context showing the app. Communicates "mobile," "shop floor," "voice."
2. **Voice-to-story animation/video** — tech speaks, waveform, finished graded story appears. Strongest "magic moment" for the value prop.
3. **Report card screenshot** — letter-grade rubric showing per-element grades with color coding. Strongest proof asset for the 3Cs pillar. (For exact criteria count by pay type, see `../shared/product-facts.md`.)
4. **MPI mobile screenshot** — color-coded carousel with status cards.
5. **Before/after story** — hand-typed tech story vs. RO.bot generated story, side-by-side.
6. **Video teleprompter screenshot** — guided recording overlay with shot list.
7. **Owner page screenshot** — customer-facing vehicle health report.
8. **Technician tracker screenshot** — performance dashboard for managers.

## Asset Sources

Screenshots come from the main RO.bot app at `../app/` (sibling subproject in the consolidated workspace). When you need a current production screenshot, run the app locally from `../app/` and capture, or coordinate with Dave for production state.

Assets per blog post live at `public/blog-assets/{N}-{slug}/`, numbered sequentially.
